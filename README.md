# Saiket Systems - Python Internship

A collection of Python tasks completed as part of the Saiket Systems internship program.

## Tasks

| # | Task | Description |
|---|------|-------------|
| 1 | ToDo List | A console-based to-do list application |
| 2 | Guess the Number | A number guessing game |
| 3 | Basic File Handling | File read/write operations |
| 4 | Basic Web Scraper | Web scraping with BeautifulSoup |
| 5 | Currency Converter | Real-time currency conversion |
| 6 | Word Count Tool | Text analysis and word counting |

## Setup

```bash
pip install -r requirements.txt
```
